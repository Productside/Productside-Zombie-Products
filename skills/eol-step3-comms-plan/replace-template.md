## Successor readiness and customer migration

| Cohort / denominator | Essential job / capability gap | Coverage / integration / migration test evidence | Price, discount, renewal, exclusions and effort | Acceptance / rollback / data permission | Support owner / escalation | Blocker / fallback / review |
|---|---|---|---|---|---|---|
| | | | | | | |

- **Successor launch conditions:** coverage, production backup/support, rollout and customer-facing terms.
- **Old-product exit conditions:** obligations met, required acceptance and safe data/support handoff; no generic cutoff for unresolved accounts.
- **Overlap and economics:** historical operations, successor rollout, parallel running and migration/exit costs separately; net releasable capacity and cash effect Unknown until evidenced.
- **Key messages (draft, gated):** why this successor, what changes/costs, migration/support plan and contact. Do not promise universal coverage or free/permanent discounts without evidence.
- **Key actions:** successor rollout; feature/price comparison; account migration/testing/acceptance; channel and bundle changes; forecasts; licensing/provisioning; materials; customer outcomes; system changes.
