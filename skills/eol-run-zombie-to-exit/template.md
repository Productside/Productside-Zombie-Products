## Artifacts

1. PLC Strategy Map (or: skipped, because)
2. Zombie ID Card
3. Cost Ledger (or: skipped, because)
4. Decision Record: all four motions ranked; named human choice/reason/date
5. Selected branch artifact: Operating Plan (Retain) / Extension Plan (Revive) / Replacement Launch and Exit Worksheet (Replace) / Retirement Closure Worksheet (Retire)
6. Announcement draft: Replace or Retire only; otherwise Not applicable / skipped
7. Capacity assessment/Transfer where relevant; otherwise Not applicable with reason. No automatic savings or reassignment.

## Selected branch check

- **Retain:** value, as-is scope, cost/capacity ceiling, owner, review date, triggers and approval status.
- **Revive:** extension hypothesis, investment, owner, outcome/test and dated evidence review.
- **Replace:** named successor, rollout/readiness, migration/acceptance and separate old-product exit conditions.
- **Retire:** no successor; lost capability, obligations, records and final support.
- **Scope/label conflict:** preserve the supplied decision and ask the Decider; do not silently relabel it.
