# Worked example: PLC Strategy Map

**Fictional product, illustrative figures.** Used across all four EOL skills so the loop tells one story.

| | |
|---|---|
| **Product** | Classic Reports: a desktop reporting portal fleet operations managers use to export weekly route and fuel reports |
| **Time in market** | Since 2014 |
| **Stage** | **Decline** |
| **Evidence** | Revenue has fallen three years running; no new customers in 18 months; a newer dashboard product (Insights) now covers most reports |

## Signals

| Signal | What we see | Points to |
|---|---|---|
| Demand | No new customers in 18 months; renewals shrinking | Decline |
| Competition | Rivals have moved to live dashboards; few still compete on desktop exports | Decline |
| Cost and margin | Support tickets per customer up three years; engine support costs rising | Decline |
| Investment | Maintenance only; no roadmap | Decline (but still more than "low") |

## Posture

| Area | Stage calls for | We are doing | Gap |
|---|---|---|---|
| Marketing objective | Maximize remaining value | Defending share with renewal discounts | **Behind** |
| Competition | Consolidate customer base | Chasing feature parity with niche competitors | **Behind** |
| Product | Streamline support | Still adding custom report types on request | **Behind** |
| Promotion | Migration campaigns | Loyalty incentives at renewal | **Behind** |
| Place | Profitable channels focus | Sold through two reseller channels, one unprofitable | **Behind** |
| Price | Selective discounting | Bundled free with Insights for some accounts | Mixed |
| Data strategy | Transition planning data | No usage tracking by report type | **Behind** |

## Transition questions

| Question | Answer |
|---|---|
| Is defending market share still profitable? | No |
| Are loyalty efforts no longer retaining users? | Yes: churn continues despite renewal discounts |
| Are legacy support costs becoming unsustainable? | Yes |
| Should we consider a product replacement? | Yes: Insights exists |
| Are we losing money on certain distribution channels? | Yes: one reseller |
| Are our value-add bundles losing effectiveness? | Unknown |
| Is data shifting from predictive to transitional? | Not yet, and it should |
